# Portfolio — Nahuel Menichetti

React + Vite + TypeScript. Modo claro/oscuro y español/inglés.

## Correr local

```bash
npm install
npm run dev
```

## Editar contenido

- Textos (en los dos idiomas): `src/data/content.ts`
- Tecnologías, íconos y grupos de skills: `src/data/tech.ts`
- Capturas de proyectos: guardalas en `public/projects/` y poné la ruta en el campo `image` de cada proyecto en `content.ts`
- Foto: `public/avatar.png` · CV: `public/Nahuel-Menichetti-CV.pdf`

## Deploy

Subí el repo a GitHub e importalo en Vercel (detecta Vite solo).

Íconos de tecnologías: [Simple Icons](https://simpleicons.org) (CC0).
